Calculation method & assumptions

1. Spherical Earth slant range
s = √(R₁² + R₂² − 2R₁R₂ cos δ)

R₁ = Earth radius + HAPS altitude; R₂ = Earth radius + UAV altitude; δ = ground arc distance / Earth radius.

2. Free-space path loss (ITU-R P.525)
FSPL = 32.45 + 20log₁₀(fMHz) + 20log₁₀(dkm)

Distance is the straight-line slant range, not the surface distance. Equivalent SI form: 20log₁₀(4πd/λ).

3. Receiver noise floor
N = −174 + 10log₁₀(BHz) + NF dBm

Assumes a 290 K reference temperature and noise figure referred to the receiver input.

4. Receiver sensitivity / minimum ideal received signal
Pmin = N + SNRrequired(MCS, BLER)

This is the minimum input signal for the selected bandwidth, noise figure and required SNR. Real modem sensitivity also depends on modulation, coding, implementation loss, BLER/BER target and standard-specific test conditions.

5. Received power
Pr = Ptx + Gtx + Grx − FSPL − Ltotal

HAPS directional gain is reduced according to the estimated off-axis pattern. The same reciprocal pattern is used for HAPS reception in uplink.

6. SNR and link margin
SNR = Pr − N ; Margin = Pr − Pmin

SNR here is noise-limited. It is not SINR because co-channel interference is not modelled.

Important modelling limitations
  • The HAPS antenna pattern is an approximate main-lobe model. Replace it with measured or manufacturer-supplied gain versus off-axis angle for design sign-off.
  • Multi-beam mode creates a one-dimensional equally spaced beam fan. It assigns each location to the nearest beam and optionally divides total HAPS transmit power equally across beams. It does not model 2D beam grids, inter-beam interference, beam scheduling, beam hopping or per-beam hardware constraints.
  • Steering angle is geometric; real phased arrays can have scan loss, element-pattern effects, polarization changes and sidelobes.
  • Earth curvature is included in slant range, but terrain blockage, Fresnel clearance, diffraction and ground reflections are not.
  • Atmospheric/rain loss is a manual allowance, not an ITU-R propagation prediction.
  • Fading margin, interference, Doppler, feeder details, regulatory EIRP limits and modem-specific sensitivity are not automatically inferred.
  • For a real 5G NR link, use the actual channel bandwidth, receiver noise figure, MCS/BLER target and vendor receiver performance data.
  • The automatic MCS threshold is a Shannon spectral-efficiency estimate with an assumed implementation gap and BLER adjustment. It is a planning approximation, not a 3GPP TS 38.214 MCS threshold or validated BLER curve. BPSK and 1024-QAM are generic/advanced options and may not be supported by a given 5G NR radio.
Reference basis: ITU-R P.525-5 for free-space attenuation; IIT Madras RF noise and sensitivity notes for the thermal-noise and sensitivity model; and ITU-R F.1336-2 for an example of a standardized reference antenna pattern. Noise and sensitivity equations use the conventional 290 K thermal-noise model.
